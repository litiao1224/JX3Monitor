# 小鹦鹉记账 - UI 重新设计方案

## 设计概述

基于用户提供的参考风格，实现现代极简深色主题设计，提升视觉层次和用户体验。

## 设计规范

### 颜色系统

#### 背景色
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主背景 | `#0a0a0a` | 接近纯黑，减少视觉噪音 |
| 侧边栏背景 | `#1a1a1a` | 深炭灰，与内容区区分 |
| 卡片背景 | `#252525` | 略浅，用于内容模块 |
| 悬停状态 | `#333333` | 交互反馈 |

#### 文字色
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主文字 | `#ffffff` | 纯白，最高对比度 |
| 次要文字 | `#a0a0a0` | 浅灰，弱化次要信息 |
| 三级文字 | `#666666` | 深灰，说明性文字 |

#### 强调色
| 用途 | 颜色值 | 说明 |
|------|--------|------|
| 主强调 | `#6b9fff` | 低饱和度蓝，用于选中态和链接 |
| 成功 | `#4ade80` | 绿色状态指示 |
| 警告 | `#fbbf24` | 琥珀色警告 |
| 错误 | `#f87171` | 红色错误状态 |

### 排版

- **字体栈**: `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'Microsoft YaHei', sans-serif`
- **基础字号**: 16px
- **行高**: 1.5（正常）/ 1.25（紧凑）

### 间距系统

| 名称 | 值 | 用途 |
|------|-----|------|
| xs | 4px | 紧凑间距 |
| sm | 8px | 小间距 |
| md | 16px | 默认间距 |
| lg | 24px | 大间距 |
| xl | 32px | 特大间距 |
| 2xl | 48px | 区块间距 |

### 圆角

| 名称 | 值 | 用途 |
|------|-----|------|
| sm | 4px | 小元素 |
| md | 8px | 按钮、输入框 |
| lg | 12px | 卡片、模态框 |
| xl | 16px | 大容器 |

## 组件规范

### 侧边栏导航

- **宽度**: 240px（桌面）/ 64px（移动端）
- **分组**: 支持导航分组，带分组标题
- **选中态**: 浅灰背景 + 左边框高亮（3px，蓝色）
- **悬停态**: 文字变亮 + 背景变化

### 输入框

- **高度**: 40px
- **边框**: 1px solid `#333333`
- **圆角**: 8px
- **悬停**: 边框变亮
- **聚焦**: 蓝色边框 + 外发光

### 按钮

- **主要按钮**: 蓝色背景，黑色文字
- **次要按钮**: 深灰背景，白色边框
- **轮廓按钮**: 透明背景，灰色边框
- **悬停**: 背景/边框变化
- **按下**: 微缩放（0.98）

### 日期选择器

- **布局**: 水平排列（年/月/日）
- **样式**: 与输入框一致
- **下拉箭头**: 自定义 SVG 图标

## 文件结构

```
docs/ui-redesign/
├── index.html      # HTML 结构（完整版）
├── preview.html    # 可交互预览页面
├── styles.css      # CSS 样式（含变量）
└── README.md       # 本文档
```

## 使用方法

1. **预览设计**: 在浏览器中打开 `preview.html`
2. **应用到项目**: 
   - 将 CSS 变量复制到项目的全局样式文件
   - 根据需要调整组件样式
   - 替换现有 UI 组件

## 自定义主题

所有颜色和间距都通过 CSS 变量定义，支持快速换肤：

```css
/* 修改主强调色 */
:root {
    --accent-primary: #your-color;
}
```

## 响应式设计

- **桌面** (>768px): 完整侧边栏
- **平板** (768px): 紧凑侧边栏
- **手机** (<768px): 隐藏文字，只显示图标

## 无障碍设计

- 所有交互元素支持键盘导航
- 高对比度文字（WCAG AA 标准）
- 焦点状态清晰可见
- 语义化 HTML 结构
